# Native autosave resident DSP guard

A stopped transport and released voices can leave a future echo, reverb, chorus, filter history or DAC metronome click. The experimental eight-track automatic-save adapter now also checks resident DSP state before every access and inside the existing IRQ-off fence before each physical mutation. Manual save policy is unchanged. This is one shared autosave, object 3, with explicit completed-migration authorization; no scheduler or boot caller invokes it or grants ownership yet.

Four volatile nonzero occupancy counters account actual truncated stores into delay, chorus, reverb comb and the reverb allpass union. Their measured retained cost is 16 bytes of normal RAM. ROOM counts 16-bit entries, SPRING counts its active 32-bit entries, and the existing complete model-change clear resets both counters before publishing the new model. The ISR owns stores/resets; main-loop eligibility performs bounded counter/scalar checks, without scanning the audio buffers or clearing musical tails.

The predicate checks delay feedback, ROOM/SPRING histories, DC/lowcut/BASS+ signal histories, pending click/envelope and all eight retained distortion histories while their track tail is active. It checks retained state even when the current control disables processing: later control changes can expose it. Harmless stable zero-signal fixed-point residues are accepted only within the proven bounds (DC error 0..4095, SPRING highpass error 0..63, lowcut errors 0..31 across modes). Other exact-zero requirements can conservatively defer saving indefinitely.
