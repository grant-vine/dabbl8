Compile-time layout assertions bind the decoded project to that arena origin. Fetch work reuses its caller's completed fence rather than creating a second nested acquisition after state has been staged.

The unchecked project/canvas primitives remain only invariant checks; operational busy policy does not rely on traps.

It checks held-plan and LCD-late nested acquisition, whole-arena preservation, current project/metadata/catalog/session preservation, raw length and name outputs, prompt state, absence of false editor confirmation, and recovery after release. No physical device or real flash is accessed. Runtime sanitizer coverage inherits the documented engine exclusions; this is not strict qualification of every DSP operation.
