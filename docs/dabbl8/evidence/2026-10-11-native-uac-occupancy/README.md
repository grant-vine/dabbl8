# Native USB48 SRC occupancy: measured partial optimization

The eight-track USB48 producer now counts its fixed 32-frame history once at block end and publishes an exact producer-local ring count. The samples, FIR tables, resampler history, packet service and logical silence refusal policy remain intact. Four-track compiled firmware remains byte-identical to the selected parent. The composed native image is 467,108 bytes, +8 versus the actual 467,100-byte current parent; RAM 95,812 and pool 334,316 bytes remain unchanged. The earlier e631-based experiment added 4 bytes, a different source scope.

This is a partial improvement, not a timing qualification. The unchanged native `uac_tap48` static cost falls from 570 to 555 against budget 504; its exact 10% limit is 554.4, so **555 still fails**. The rounded percentage in the raw report does not change that result. No thresholds or golden hashes changed. The inherited arrangement `fm1_alnk0_irq` also fails at 54,935 versus 37,502. These are the two static failures in the final composition. Physical FIFO/codec drain, worst-case IRQ deadlines and device recovery remain untested gates.

Source scopes are recorded in results.json: initial frozen source `0978023e794409e89994cec7009b832f63b6d2bb` on mainb0, composed corrected source `a80c2bbceae0fe5f36801eca0ac2e3a9ee35321a` on exact main `c5c96236ce275072adaaaca35c2046098384b2e9`, and a later docs-only evidence commit. The original afc experiment has identical production inputs and its measurements remain labelled with that original source. Do not infer a release or hardware pass from a green default-four CI job.

The retained fixture is the byte-exact `uac_tap48` function from e631, with the rename supplied only by the test. Both normal and autonomous TONE tests compare all 160 phases, every input length 0..64, and random/zero/single-impulse-drain histories: 31,200 cases per executable. Independent scans check all ring slots, duplicated history and exact nonzero occupancy; tests also retain consumer-owned packet/uncertainty state and unchanged overrun refusal. This reference is synthetic host code, not vendor firmware or a private device capture.

Optimized and inherited DSP sanitizer checks run the same matrix. The inherited configuration uses ASan/UBSan while excluding signed-integer-overflow, shift, bounds, object-size and pointer-overflow in the existing DSP code. It is not a strict sanitizer pass for all production DSP. Existing queue tests exercise real simulated SIE service, natural drain and every late physical-adapter refusal; they do not prove real hardware completion.

TIMER5 may nest in the audio producer but only consumes packets; it does not mutate ring/history counts or authorize flash writes. Main-loop eligibility takes a fresh IRQ-off read after the producer completes. Counts publish before the existing memory barrier and write-index publication. No queue is cleared to obtain eligibility. Target function frame evidence records only this function, not complete stack high-water use.

Five fresh solo alternating host benchmark batches (25 rounds per source/input/consumer mode) on the final composition show about 4.8–5.6% fewer instructions and 0.40–0.88% lower elapsed medians. Earlier equivalent production-source measurements ranged from a 0.96% reduction to a 0.29% increase. Other Mac activity was uncontrolled; no blanket elapsed-time or hardware-cycle benefit is claimed. Actual DAC/USB/history/packet output matches the parent byte-for-byte.

The private research retained ten isolated candidates. Compiler no-ops and failed pair-copy traversals are summarized honestly; a shared-array pointer experiment was rejected and replaced by legal separate-array pointers. A separate zero-history shortcut has useful silent-load savings but worse active static cost and is not included here.

The first full run retained a test-only compile failure: an unset TONE macro was referenced by printf. Standalone flags had masked that mismatch. A test-only default fixed it; actual runner flags are used in the final checks. The full-run orchestration copied an outdated single-failure metadata constant; the derived scope report lists both actual raw native static failures and preserves original terminal metadata.

No flashing, loader or flash-boundary changes, firmware release, deployment or automatic persistence activation is part of this change.

The completed Mac suite retains four actual omissions: the external DaisySP PHYS reference, the official V15 vendor-package restore fixture, inherited editor MENU settings absent from that fixture, and the Emscripten browser emulator. The vendor package is not committed. All 92 golden renders remain unchanged, and the new normal/TONE matrix passes in both optimized and inherited sanitizer modes.
