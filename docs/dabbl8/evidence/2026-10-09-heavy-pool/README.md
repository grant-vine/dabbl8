# Shared GRAIN/PHYS/DRUM state — engine-pool fit achieved

Preparatory #12 work stacked on SLICE PR32. Expanded builds share eight typed union bodies across expensive engines. Each sounding PHYS voice needs one body; each active GRAIN or DRUM track needs one complete part/kit body. Because every allocated body has at least one sounding voice, the eight shared sounding voices bound the number of admitted bodies to eight. Inactive block callbacks do not reserve slots; track-wide engines reject duplicate voice-index owners. Same-owner state remains intact. Reclamation requires an inactive or changed-engine owner, clears the new engine member, and refuses unadmitted state when full. Typed union members preserve alignment/alias rules; no malloc or opaque byte-buffer casting is introduced.

Engine limits are retained: GRAIN three voices and twelve grains per active track (including its full seek index/reverse windows), PHYS three bodies per track, DRUM complete eight-lane kits with choke/metal state. No engine is disabled. Inactive GRAIN callbacks no longer prebuild a resident index; a reclaimed part rebuilds on activation. Startup/transition sound and target deadline/high-water qualification therefore remain open. Continuously active audio is checked separately below.
