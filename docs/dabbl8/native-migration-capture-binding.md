# Private binding to the earlier instrument capture

This dormant main-loop component binds the actual completed full 17-role editor capture to a received native proposal. It performs no device writes, live adoption, native binding, retention acknowledgment, consent grant or public protocol operation. Application-write quarantine remains closed. The capture is post-boot; it does not establish pre-boot recovery originals.

BEGIN requires the actual active full capture in phase 4 after its raw rescan and RAM revalidation. It privately freezes the token, USB lifetime, mutation epoch, original 17 CRCs and canonical current-project length before acquiring the migration arena. No caller supplies source CRCs or a validation receipt. All five RAM roles are rechecked against that earlier capture. After LCD synchronization and ownership acquisition, actual current state is captured in the existing owned buffer and checked again, alongside settings, banks and FM6. A later edit cannot become a new silently accepted capture identity. Successful takeover revokes the old public capture; failure preserves the caller's output. Outputs must be private caller storage disjoint from all live globals; sensitive arena/session metadata aliases explicitly refuse.

The existing sequential receive operation still bounds chunks to 256 bytes and requires the complete 40,960-byte plan. Source equivalence uses only privately frozen original CRCs; explicit CURRENT completion must also match the earlier current length/CRC. PERSISTED and CURRENT remain distinct choices. Torn, ambiguous, unsupported and unrepresentable historical material refuses rather than silently converting it. The actual full-current capture already refuses unconverted historical chains it cannot represent; this component does not invent a fallback.

Before actual canonical validation changes preflight phase 1 to phase 4, completion is consumed and the plan CRC is retained in disjoint private metadata. The later metadata predicate checks ownership/generation, configuration/reset, flash availability, stopped transport, mutation epoch, timeout and complete-receive phase. It never recaptures, encodes or reads/writes staging, so it cannot overwrite executor readback. A coordinator must also compare the actual executor's canonical plan CRC and original CRCs with this private context. The simulator does that at every callback; production has no consumer yet.

**This predicate is not write permission.** It cannot detect arbitrary unobserved RAM edits after sealing: an explicit diagnostic demonstrates that limit. Production coordination still must exclude all editing/transport paths, serialize writer/driver IRQ boundaries, account for its own authorized observed mutations without accepting unrelated ones, verify independently retained external originals and explicit consent, perform the executor's independent original reread before erase, reconcile failure and deliberately adopt/bind only after complete readback. Caller-provided metadata or a successful simulation cannot substitute for these requirements. Whole migration is not power atomic. Actual hardware timing, stack high-water and recovery remain unverified.

The fixture performs the actual public full capture GET/scan/rescan sequence against simulated NOR, then the actual private binding, source comparison, canonical validation and bounded executor. It covers both autosave choices, every preserved byte outside five destination pairs, exactly 10 erases/170 programs, stage-preserving executor guards, raw-only/incomplete capture refusal, all five actual RAM-role edits before BEGIN, LCD-time edits/config/observer/token changes and recursive BEGIN refusal, a later CURRENT proposal, original source corruption, post-seal session revocation and newer-owner preservation. Optimized and strict address/undefined sanitizer focused runs pass 12,098,203 checks each, without sanitizer exclusions. The initial 54 failures arose from a deliberately alignment-checking importer receiving the test helper's unaligned byte array (actual symbol ended in 0x695); `_Alignas(4)` makes the valid-input fixture portable. A second two-failure run exposed a noncanonical test proposal spare block and overly specific corruption status expectation; both raw logs are preserved, no production refusal was weakened.

Fresh frozen targets, full upstream checks, public source/log manifests and combined-main verification remain required before publication. An uncalled component can be removed by the linker; unchanged target bytes would not measure an activated coordinator's footprint or performance.
