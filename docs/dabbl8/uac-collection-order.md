# USB audio collection order

This narrowly backports the AudioControl collection-order fix from Felucca v1.5.1, commit `a4d7ca2e5d52a4c35e2468401f00d883cadbda03`. With USB audio enabled, `FELUCCA_UAC_AS_FIRST=1` (default) lists the audio streaming interface before MIDI in the collection. Physical interface and endpoint numbers, sample rates, device classes and PID remain unchanged. The device version uses a reserved decimal +40 band (BCD 3.50–3.57 for 44.1 kHz and 3.60–3.67 for 48 kHz) to distinguish cached descriptor sets. This intentionally corrects literal upstream +0x08: some CDC layouts otherwise produce invalid BCD digits, and decimal +8 alone collides across rates. [Apple’s descriptor definition](https://developer.apple.com/documentation/usbdriverkit/iousbdevicedescriptor/bcddevice) requires binary-coded decimal. `FELUCCA_UAC_AS_FIRST=0` preserves the old descriptor bytes; disabling UAC forces this option off.

The rationale is source-informed, with older-macOS hardware enumeration still unconfirmed here. Upstream identifies AppleUSBAudio's MIDI collection pruning. The Apple-origin 273.4.1 source retained in the [nickdowell mirror](https://github.com/nickdowell/AppleUSBAudio-273.4.1/blob/62fcb03e2c2ea5c5335b4b488d897d8f7a5ca020/AppleUSBAudioDictionary.cpp) removes a MIDI entry while iterating the original collection count and rejects a missing array entry. This inspection supports the ordering change; it does not establish which exact parser ships on every macOS release or prove enumeration on an FM-1. No Apple code is copied into the firmware.

The actual GET_DESCRIPTOR matrix covers CDC built/not built, console presented/hidden, layouts 0–3, no audio/44.1 kHz/44.1+48 kHz and legacy/modern order. It checks complete bytes, class/subclass roles, endpoints, interface numbers and valid BCD cache versions with no collisions between distinct complete descriptor sets; runtime console changes match independently compiled views. The released V1.0 descriptor fixtures remain immutable. Modern expectations derive only the two collection bytes and cache version from those fixtures; legacy mode still has the full byte oracle. An optional privately retained parent source provides exact parent comparisons across the matrix.

Adjacent checks exercise the existing resampler/packets, actual DMA/USB queue publication, shipping migration refusal, connected host simulation and identity assertions. Descriptor parsing tests are software coverage, not an emulation of AppleUSBAudio or physical enumeration. No assigned USB VID/PID claim is introduced. The loader and flash map are untouched; this changes both four- and eight-track app descriptors intentionally and does not claim pristine app binary identity. Shipping writes remain quarantined and native deadline/physical recovery gates remain open.
