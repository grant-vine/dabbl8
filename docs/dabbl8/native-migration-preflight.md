# Readonly native migration staging and complete-set preflight

This is a preparatory main-loop API, dormant in production. It receives and validates a complete proposed pool without writes, runtime adoption, native binding or authority. It does not complete migration or make permanent quarantine the final product behavior. All17 captured originals, including the fourth historical project and distinct saved/current auto state, remain externally retained. Trusted source-equivalence review, physical execution/readback, runtime adoption, ownership and boot/session policy remain separate dependencies.

The existing59520-byte LCD canvas arena has a new58432-byte member: existing17472-byte state/wire staging at offset0 plus40960-byte immutable proposed pool. Static and pinned target compiler IR assertions verify sizes/offsets/alignment. No second project-sized state or pool buffer is allocated. Owner generation and receive-phase metadata use20 bytes of `.pool` storage in source; actual linked resource evidence is measured separately, and unused dormant functions may be removed.

`d8mp_begin` refuses CPU drawing/already-held/exhausted generation with BUSY before publishing a token. It fences pending LCD DMA and invalidates pixels. Generations never wrap. `d8mp_receive` accepts ordered chunks at most256 bytes without crossing a page, rejects gaps/range overflow and arena/metadata aliases, and never accepts a stale owner. No partial or complete transfer grants permission.

`d8mp_validate` requires all40960 bytes, then calls actual C inventory/load and structured decoder for the entire set with final manual reference mask. Shared auto object3 is required, and all three manual object positions remain distinct. Header/payload padding and every noncurrent block must be erased; unknown/unsupported content, absent/fourth references, ambiguous generations, bad records and noncanonical roundtrips refuse. Decode/encode uses disjoint existing state/wire while the plan remains unchanged. Only bounded generation/CRC/inventory metadata is published outside the arena after success; failure preserves caller result. `d8mp_end` revokes arena lifetime and cannot be used with a stale token.

Ordinary `ui_draw` defers before touching the arena and requests redraw after release. Legacy unchecked project/native borrow and canvas primitives retain defensive traps if called while an exclusive plan is held. **These traps are assertions, not operational policy. Before any production caller activates this API, every legitimate competing editor/capture/one-shot project route must gain checked refusal or deferral, and the whole transaction must whitelist main-loop work.** The audio ISR owns no arena member; no pointer can survive release/drawing. Callback reentry and side-channel writes to staged memory are outside the trusted synchronous API contract.

The proposed bytes are a validated native set, not proof of preserved legacy music or durable external backups. CRC/generation is consistency evidence, not authentication. Protocol frames, catalogue recognition and native binding cannot mint migration authority. A future separately approved trusted coordinator must validate source-to-plan equivalence before first erase, retain quarantine across cuts, use bounded existing driver operations/readback, adopt chosen live state and then bind/begin with explicit boot policy. Loader/maps/boundaries, audio hashes and static cost references remain unchanged.

Host tests exercise actual LCD DMA/UI/codec/pool paths, all five writer-selected autosave positions, eight tracks, valid references, fourth-reference/unknown/noncanonical refusal, unused-tail canaries, nested/late acquisition and stale/alias/phase errors. Inherited DSP sanitizer exclusions are explicit; compiler IR layout does not establish linked stack/timing or physical safety. Native UAC/ROOM/SPRING static overruns and issue12/device recovery/deadline gates remain open.
